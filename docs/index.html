Overview

Probe and reshape unit text streams with deterministic transforms. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/probeunit.git
cd probeunit
node src/cli.js --help
node --test
